## 二、v3.2 地理锚定（本次核心修订）

**机制**：`AmapMapContent` 每次相机变化/渲染时回传 `FogGeoFrame`：

| 字段 | 含义 |
|---|---|
| `originScreen` | 迷雾锚点（`fogAnchorPoint()` = 全部地标包围盒中心，演示/高德共用同一算法）的屏幕像素坐标 |
| `pxPerMeter` | 锚点东向 500m 参考点实测投影距离 ÷ 500，当前缩放下的每米像素数 |

云场绘制（`drawGeoCloudField`）：

1. **米制无穷网格**：网格步长 160m×140m（对应原型列距 16%/行距 14% × 视口 1000m 基准），网格点 (i,j) 对应地面固定位置；云形/缩放/翻转/旋转/抖动参数按 `(i mod 9, j mod 9)` 从原型 9×9 场**取模复用**，确定性一致；相位对齐原型错位布局（X+20m / Y−20m）。
2. **滑动跟随**：每朵云按 `originScreen + 地理偏移×pxPerMeter` 落屏 → 拖动地图时云与地图 1:1 同步移动（parallax=1）。
3. **缩放随比例尺**：云体尺寸与孔半径按 `k = pxPerMeter × 1000 / 390` 缩放（默认视角 k ≈ 屏宽/390，与 v3.1 屏幕比例版视觉等价）；放大地图云变大、缩小地图云变小，即「迷雾套在地图上」。
4. **漂移仍锚定地面**：漂移幅度换算为米（±18m/±10m），云在地面位置上轻摆而不是在屏幕上漂。
5. **极远缩放保护**：网格间距 < 170px 时按 stride 抽稀（只画 stride 倍数网格点），云体放大至间距 ×1.9 保覆盖；绘制数量上限 ≈ (屏宽/170)×(屏高/150) ≈ 110 朵，帧率有界。此时云体略大于地理真实尺寸（仅极端缩小视角，位置仍锚定）。
6. **已打卡孔**：半径 `104px × k`（跟随缩放），下限 30dp 保可见；marker 30dp 小孔保持屏幕 dp（透出原生 marker 与缩放无关）。
7. **小云飘散**（新打卡 fogpuff）：位移换算为米（横向 ±22+246·t m、纵向 97~178m），尺寸随 k。

**降级**：`geoFrame` 尚未回传前（地图首帧 ~0.5s）FogOverlay 自动走 v3.1 屏幕比例网格，锚定帧到达后无缝切换；演示地图（不滑动）固定走屏幕比例路径，行为不变。

## 四、交互动画（与 v3.1 一致）

| 行为 | 实现 |
|---|---|
| 静态孔（历史打卡） | 首帧差分初始化不重播，直接全半径（对应原型「静态孔」） |
| 新打卡孔生长 | `Animatable 0→1`，tween 1700ms + delay 120ms，缓出 `CubicBezierEasing(.22,.7,.3,1)`，对应 SMIL `dur=1.7s keySplines="0.22 0.7 0.3 1"` |
| 小云飘散 | 5 朵（方向 `[-1.15,-.6,.05,.62,1.1]`），各延时 k×120ms，1.9s 内飘出淡出（地理路径位移换算米），对应 `p01fogPuff` |
| 差分触发 | `LaunchedEffect(completedLandmarkIds)` 对比上一帧集合，只对新增 id 启动动画（对应原型 `FOG_SEEN` 差分） |
| 全图揭示调试 | `debugRevealAll=true` 时整层不绘制（调试面板「显示全图」语义不变） |

## 七、已知限制 / 后续项

1. 云层为逐帧 Canvas 重绘（地理路径有 stride 上限保护）；如真机掉帧，可将当前视角云场预烘焙为 `ImageBitmap`，相机平移时整体平移烘焙图。
2. 锚定帧在相机**连续手势中**按 `onCameraChange` 刷新（高德回调频率内跟手）；极快速拖动时孔/云与地图可有 ≤1 帧延迟，松手即对齐。
3. 高德 marker 小孔为圆形固定 30dp；若后续水滴样式改大或加标注气泡，需同步调 `MARKER_HOLE_DP`。
4. 极远缩放（整城视角）时云体按 stride 放大覆盖，地理真实性让位于覆盖性；校园视角（产品主场景）完全按地理尺寸渲染。
5. 孔半径下限 30dp；若产品要求「孔不连片」硬约束，可加相邻孔最小间距钳制（当前与原型一致，未加）。
