## 一、实装范围与边界

| 项 | 口径 |
|---|---|
| 生效路径 | 仅演示地图 `DemoMapContent`（原型 P01 对应的地图形态） |
| 真实高德地图路径 | 不叠加卡通云层，沿用既有 `FogPolygonOverlay`（AMap polygon 迷雾），避免在真实地图上遮盖导航要素 |
| 层级 | 迷雾画在**底图之上、地标水滴之下**（对应原型 fog z5 < pins z7），整层 `pointer-events` 穿透，不影响点击 |
| 原设计改动 | 零改动：底图网格/楼块/道路、水滴、底卡、分段控件全部保持原样，迷雾为纯新增叠加层 |

| 云体/高光/投影 | `#B9D4B5` .86 / `#E6F1E2` .78~.80 / `#89A687` .28~.32 | 三层色阶 |

| 云场 | 9×9 网格错位叠铺（−12%~116%），跳过 `(r*5+c*3)%11==0`，抖动/缩放/翻转/旋转公式与原型逐项一致 | `fogCloudField()` |

## 三、交互动画

| 行为 | 实现 |
|---|---|
| 静态孔（历史打卡） | 首帧差分初始化不重播，直接全半径（对应原型「静态孔」） |
| 新打卡孔生长 | `Animatable 0→1`，tween 1700ms + delay 120ms，缓出 `CubicBezierEasing(.22,.7,.3,1)`，对应 SMIL `dur=1.7s keySplines="0.22 0.7 0.3 1"` |
| 小云飘散 | 5 朵（方向 `[-1.15,-.6,.05,.62,1.1]`），各延时 k×120ms，1.9s 内位移 ±96px·向上 38~70px、放大至 1.3×、alpha .5→0，对应 `p01fogPuff` |
| 差分触发 | `LaunchedEffect(completedLandmarkIds)` 对比上一帧集合，只对新增 id 启动动画（对应原型 `FOG_SEEN` 差分） |
| 全图揭示调试 | `debugRevealAll=true` 时整层不绘制（调试面板「显示全图」语义不变） |

## 六、已知限制 / 后续项

1. 云层为逐帧 Canvas 重绘（~70 朵 × ~12 元素），原型同规模；如真机出现掉帧，可将静态云场预烘焙为 `ImageBitmap`、仅保留漂移层实时绘制。
2. 真实地图（AMap）路径的迷雾视觉仍是旧的多边形方案，如需同款卡通云层需依赖 AMap 屏幕坐标投影，建议单独立项。
3. 孔半径随画布宽度等比缩放；若产品要求「孔不连片」硬约束，可在 FogOverlay 内加相邻孔最小间距钳制（当前与原型一致，未加）。
