## 一、实装范围与边界（v3.1 修订）

| 项 | 口径 |
|---|---|
| 生效路径 | **双路径全覆盖**：演示地图 `DemoMapContent` 与真实高德地图 `AmapMapContent`（MapScreen `shouldUseAmap` 分支） |
| 旧深灰迷雾 | **两条路径均退役**：DemoMapContent 画布已删、AmapMapAdapter 不再调用 `FogPolygonOverlay`（类保留备查） |
| 高德路径层级 | FogOverlay 作为 Compose 层叠加在 AMap `AndroidView` **之上**、品牌头图/底卡**之下**；AMap 原生 marker 在本层之下 |
| marker 可见性 | 高德路径在**每个可见 marker 处开 30dp 软边小孔**透出水滴（marker 在雾下无法直接浮层）；已打卡地标另开 104px 大孔 |
| 孔位投影 | 高德路径用 `AMap.projection.toScreenLocation` 实时投影地标屏幕坐标，相机移动（`CameraMoved`）/每次 render/地图首帧轮询兜底（0.5s+0.7s×5）时刷新，孔随相机跟手 |
| 演示路径层级 | 迷雾画在底图之上、水滴（Compose marker）之下，与原型 z5<z7 一致，无需 marker 小孔 |
| 原设计改动 | 零改动：底图、水滴、底卡、分段控件全部保持原样，迷雾为纯新增叠加层，`pointer-events` 穿透 |

## 三、交互动画

| 行为 | 实现 |
|---|---|
| 静态孔（历史打卡） | 首帧差分初始化不重播，直接全半径（对应原型「静态孔」） |
| 新打卡孔生长 | `Animatable 0→1`，tween 1700ms + delay 120ms，缓出 `CubicBezierEasing(.22,.7,.3,1)`，对应 SMIL `dur=1.7s keySplines="0.22 0.7 0.3 1"` |
| 小云飘散 | 5 朵（方向 `[-1.15,-.6,.05,.62,1.1]`），各延时 k×120ms，1.9s 内位移 ±96px·向上 38~70px、放大至 1.3×、alpha .5→0，对应 `p01fogPuff` |
| 差分触发 | `LaunchedEffect(completedLandmarkIds)` 对比上一帧集合，只对新增 id 启动动画（对应原型 `FOG_SEEN` 差分） |
| 全图揭示调试 | `debugRevealAll=true` 时整层不绘制（调试面板「显示全图」语义不变） |

## 六、已知限制 / 后续项

1. 云层为逐帧 Canvas 重绘（~70 朵 × ~12 元素）；如真机掉帧，可将静态云场预烘焙为 `ImageBitmap`。
2. 云场锚定屏幕（毛玻璃式覆盖）：高德地图平移时云纹不动、孔位跟手（存在一帧延迟）。若需云纹锚定地理坐标（拖动时云跟着地图走），需改为按地理边界铺云 + 每帧投影，建议单独立项。
3. 高德 marker 小孔为圆形固定 30dp；若后续水滴样式改大或加标注气泡，需同步调 `MARKER_HOLE_DP`。
4. 孔半径随画布宽度等比缩放；若产品要求「孔不连片」硬约束，可加相邻孔最小间距钳制（当前与原型一致，未加）。
