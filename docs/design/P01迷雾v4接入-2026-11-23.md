# P01 迷雾 v4 接入说明（E「连续云层·步行开雾」第二版）

- 日期：2026-11-23
- 依据：E 交付《给A-迷雾接入包.zip》（README-接入说明.md + fog-cloud-texture.png + north-walk-reference.png）
- 取代：v3.2「卡通云场 + Clear 开孔」（地理锚定 9×9 云网格）整套渲染

## 设计落地

| E 设计要求 | 实现 |
| --- | --- |
| 云纹独立不透明、透明度软件计算 | 单张 `fog-cloud-texture.png`（assets 根，512m/格地理锚定平铺）+ ALPHA_8 遮罩逐点透明度（`FogMaskBuilder`） |
| 校外雾 alpha 恒 1、遮住校界外底图 | 遮罩全图先填 1；围界外（含遮罩范围外）均为不透明云层 |
| 校界内侧才羽化 | 围界描边（半宽=羽化宽）+ 模糊，界内从 1 渐落回 0.35，界外保持 1；`BOUNDARY_FEATHER_M=45m` |
| 未探索 0.30–0.40 起调 | `UNEXPLORED_ALPHA=0.35`；围界多边形内填 0.35 |
| 临时视野/历史探索带中心清晰、边缘回落 | DST_OUT + 径向渐变揭雾；临时半径 `TEMP_VIEW_RADIUS_M=60m`、单探索点 `EXPLORED_RADIUS_M=60m`（记录间隔沿用 `EXPLORATION_RECORD_DISTANCE_METERS=10m`，步行点密集重叠自然连成带） |
| 打卡成功整块点亮、边缘过渡 | 复用 `campusRevealBlocks`（分区 tile）DST_OUT + 30m 模糊；点亮瞬间保留柔光脉冲 + 5 朵小云飘散动画 |
| 揭雾权重取最大混合 | DST_OUT 乘法衰减在密集重叠处趋近 max 效果（带中心趋近全清） |
| 校外全遮挡优先 | 遮罩管线第 1 步为全图填 1，任何揭雾都发生在界内 |
| 云纹随地图平移/缩放（同相机坐标） | 云纹格与遮罩共用 FogGeoFrame（锚点屏幕坐标 + pxPerMeter），高德路径由 projection 实测 |
| 层级 底图<云层<地标<UI | AMap 原生 marker 在云层之下，可见 marker 开 30dp 小孔透出；演示路径 marker 在云层之上 |
| 校外无文字/业务标记裁切 | 云上无任何文字；12 地标均在界内，界外无业务标记 |

## 数据与文件

- `core/model/CampusFences.kt`（新增）：三区 OSM 围界多边形（28/16/18 点），源
  `campus-unified-v5/sources/campus-scale-controls.json`，WGS84→GCJ-02 迭代转换（与 v12 底图验收同源）。
- `feature/map/FogMaskBuilder.kt`（新增）：遮罩构建（后台线程，状态变化触发）。
- `feature/map/FogOverlay.kt`（重写）：云纹平铺 + DstIn 遮罩 + marker 小孔 + 飘散动画。
- `feature/map/MapScreen.kt` / `DemoMapContent.kt`：传入 `exploredCenters`/`liveScoutCenter`；
  演示路径由 `DemoMapProjection` 合成锚定帧（暴露 originPoint/eastSpan/northSpan）。
- 退役：v3.2 云场/雾底/已完成大孔全部删除；`core/map/FogPolygonOverlay.kt`（旧深灰迷雾，早已无引用）
  因沙箱删除拦截暂留档，无编译影响。

## 调参入口（全部集中在 `FogMaskParams`）

未探索浓度 / 羽化宽度 / 揭雾半径 / 打卡过渡宽度 / 遮罩分辨率（0.6px/m）。

## 已知边界与待验收

- 云纹接缝：E 说明未验证无缝平铺；512m/格下若真机可见接缝，请 E 交付无缝平铺版或更大云纹。
- 远缩放云纹分辨率：放大镜级别（>20px/m）云纹有放大模糊，属贴图方案固有；参考图本身就是柔和云层。
- 首轮验收按 E 说明四条：①平移/缩放/旋转校外无漏出、界两侧云纹连续；②未探索可辨认主路、
  步行后可见视野与历史开雾带、定位失效回落历史；③发现与打卡反馈可区分、打卡整块点亮不过界；
  ④实际校界/定位/业务状态以 App 内验证为准。
- demo（无高德）路径同一渲染管线，遮罩按演示投影合成帧。
