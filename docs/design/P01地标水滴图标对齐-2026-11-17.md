| 项 | 原型 | 本次实现 |

| 底色 | `#00634D`，描边 `#004B3A` (1.2) | **2026-11-19 改版：`#00634D` 主体 + 白描边 2.8**（按用户给图） |
| 头部 | 无内圆，符号直接压绿底 | **白色内圆 r=7.6 居 (17,14.2)**（11-19 二次微调，原 7.9），环厚约 2.8 单位 |

| 投影 | `drop-shadow(0 3px 6px rgba(32,41,35,.18))` | 尖端下方椭圆投影（位图用 BlurMaskFilter，Compose 用两层椭圆近似） |
| 名称标签 | 仅 done 态显示名称 | 本轮不画（地图已有卡片/选中态信息），待评审确认 |

## 二、实现

| 文件 | 作用 |
| --- | --- |
| `core/map/LandmarkPinBitmaps.kt` | 高德 marker 位图工厂：`buildDropPath(s)` 复刻 PIN_D；`create(isDone, widthPx)` 生成两态位图（画布 34×38）；常量 `ANCHOR_Y = 32.4/38`、`HEIGHT_RATIO`、`CENTER_X/Y`、`TIP_Y` 与 Compose 版共用 |
| `feature/map/LandmarkPin.kt` | Compose 版（演示地图）：同几何同配色，画布 34×38dp；问号用 `TextMeasurer` 居中，勾线圆头，投影用两层椭圆近似柔边 |
| `core/map/AmapMapAdapter.kt` | marker 换 `pinIcon(done)`、`anchor(0.5f, LandmarkPinBitmaps.ANCHOR_Y)`（尖端钉坐标、投影落在下方）；`reconcileLandmarks` 带 `completedLandmarkIds`，打卡后自动换勾 |
| `feature/map/DemoMapContent.kt` | 旧 `FilledIconButton + LocationOn` 圆钮退役，改 `LandmarkPin`；`isDone = id in completedLandmarkIds` |

两条渲染路径（高德真图 / 演示地图）共用同一几何与配色，位图与 Compose 两处需同步修改。
