## 一、口径

原型 `design/prototype/index.html` 的 `dropPin(done, label)`（`PIN_D`，34×34 视口）：

| 项 | 原型 | 本次实现 |
| --- | --- | --- |
| 形状 | `M17 32.4C17 32.4 6.6 21.6 6.6 14.2a10.4 10.4 0 1 1 20.8 0C27.4 21.6 17 32.4 17 32.4Z`（倒立水滴，尖端 (17,32.4) 为锚点） | 同一条路径，双路径共用同一几何 |
| 底色 | `#00634D`，描边 `#004B3A` (1.2) | 一致 |
| 打卡后 | 白勾 `M11.7 14.4 l3.6 3.6 l7.1 -7.8`，白 2.7 圆头圆角 | 一致 |
| 打卡前 | 原型为 `#FFFEFA` 白底 + 深绿问号（stroke 2） | **按用户要求改为深绿底 + 白色问号**（唯一有意偏离，已在代码 KDoc 注明） |
| 名称标签 | 仅 done 态显示名称 | 本轮不画（地图已有卡片/选中态信息），待评审确认 |

## 二、实现

| 文件 | 作用 |
| --- | --- |
| `core/map/LandmarkPinBitmaps.kt` | 高德 marker 位图工厂：`buildDropPath(s)` 复刻 PIN_D；`create(isDone, sizePx)` 生成两态位图；`pinSizePx()` 按 34dp × density |
| `feature/map/LandmarkPin.kt` | Compose 版（演示地图）：同一路径 + 同一配色；问号用 `TextMeasurer` 居中，勾线带圆头 |
| `core/map/AmapMapAdapter.kt` | marker 换 `pinIcon(done)`、`anchor(0.5f, 1f)`（尖端钉在坐标上）；`reconcileLandmarks` 增加 `completedLandmarkIds`，打卡后自动换勾 |
| `feature/map/DemoMapContent.kt` | 旧 `FilledIconButton + LocationOn` 圆钮退役，改 `LandmarkPin`；`isDone = id in completedLandmarkIds` |

两条渲染路径（高德真图 / 演示地图）共用同一几何与配色，位图与 Compose 两处需同步修改。
