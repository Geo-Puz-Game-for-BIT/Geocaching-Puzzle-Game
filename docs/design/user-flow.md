## 1. 主线（13 步，正常路径）

| # | 玩家动作 | 页面 | 系统响应 | 数据变化 |
|---|---|---|---|---|
| ① | 打开 App | 启动页 | 读本地登录态，静默续登；无登录态则展示手机号登录 | `User` 恢复 |
| ② | 首次进入授予定位 | 系统弹窗 | 请求 `ACCESS_FINE_LOCATION`；拒绝则进 F1 | 权限态写入 |
| ③ | 看地图找地标 | P01 地图 | 定位 → 拉取南校区 4 个地标 → 画 Marker + 底部卡片 | `Landmark` 列表 |
| ④ | 点卡片看详情 | P02 详情 | 展示介绍、实时距离、难度、任务说明、按钮态 | `Task` 绑定 |
| ⑤ | 点「去打卡」 | P03 相机 | 请相机权限 → 取景预览 + 距离/精度浮层 | `Checkin` 草稿建立 |
| ⑥ | 拍照 + 提交 | P03 相机 | 照片压到 ≤1280px、取定位快照、提交 | `Checkin.state=PENDING` |
| ⑦ | （无感）校验 | — | 距离≤30m、accuracy≤20m、照片有效 | `SUCCESS` / `FAILED` |
| ⑧ | 看结果 | P04 结果 | 成功页：该地标碎片 +1、进度 `3/4→4/4`、「去拼合南校区」 | `Module.tiles` +1 |
| ⑨ | 进片区拼图 | P05 片区拼图 | 2×2 网格：刚打的这一格亮起并显示地名，其余灰锁 | `tiles.owned` |
| ⑩ | 系统判断片区集齐 | P05 片区拼图 | `4/4` → 播放拼合动画 | `Module.completed` |
| ⑪ | 拿片区奖励 | P05 片区拼图 | 「成就 · 拼合南校区」+ 提示地图进度 `1 / 3` | `achievements` +1 |
| ⑫ | 回地图总览看另一片区 | P05 地图总览 | 三片区并排：`MP-A 已合成`、`MP-B 1/4`、`MP-C 0/4` | `Map.completedModules=1` |
| ⑬ | 三片区都齐 → 成图 | P05 地图总览 | `12/12` 金色 + 「成就 · 校园地图完成」 | `Map.completed=true` |

**关键时序**：⑥ 提交是唯一不可逆动作，必须"先落草稿，再上传"。任何失败都能回到草稿重试，
不允许出现"拍了照、网断了、照片没了"。

**两级奖励**：⑩⑪ 是**片区级**（4 块 → 1 个模块），⑫⑬ 是**地图级**（3 模块 → 1 张图）。
P0 演示走通 ①–⑪（南校区整条链路）；⑫⑬ 用预置数据演示，`MP-B` / `MP-C` 的打卡留到 P1。

## 2. 五页之间的跳转关系

```
            ┌──────────── 返回 ────────────┐
            ↓                              │
P01 地图 ──点卡片──> P02 详情 ──去打卡──> P03 相机 ──提交──> P04 结果
   ↑                                            │              │
   │                                            └─失败─> 留在 P03（重拍/重试）
   │                                                           │去拼合片区
   │                                                           ↓
   └──── 去地图继续打卡 ──── P05 片区拼图（2×2） ──返回──> P05 地图总览（3 片区）
                                  ↑                            │
                                  └──────── 点片区进来看 2×2 ───┘
```

- **P05 是同一页的两级视图**：默认落在「地图总览」，点任一片区进入该片区 2×2；片区页返回键回总览，总览返回键回 P01。
- **返回键行为**：P03 → P02（保留草稿）；P04 成功 → 不可回退到 P03（照片已消耗），只能去 P05 或回 P01；
  P05 片区 → P05 总览 → P01（进度全程保留）。
- **深链**：`gt://landmark/LM-001` 直达 P02；`gt://puzzle/MP-A` 直达该片区 2×2；`gt://map` 直达总览。
- **不做**：页面间共享转场动画之外的花哨动效；不做侧滑抽屉、不做多 Tab 嵌套。

## 3. 状态机（任务 / 打卡 / 拼图）

```
任务：未开始 ──进入 P02──> 进行中 ──提交──> 待校验 ──通过──> 成功
                                              │
                                              └──不通过──> 失败 ──重拍/重试──> 进行中

打卡：DRAFT ──提交──> SYNCING ──成功──> SUCCESS
                        │
                        ├──网络失败──> DRAFT（标记「未同步」，联网自动重试）
                        └──校验失败──> FAILED（附 failReason，可重拍）

模块（片区）：0/4 ──每次打卡──> n/4 ──n=4──> 待拼合 ──拖拽归位完成──> 已合成
                                                    │
                                                    └── 未归位 ──> 待拼合（可随时离开）

地图：0/3 ──合成一个模块──> 1/3 ──> 2/3 ──> 3/3（完整地图 + 终极成就）
```

`failReason` 与界面文案的映射见 `docs/scope.md §4`，文案正文见 `design/copy/文案.md`。

## 4. 失败恢复（每条都要有出口）

| 编号 | 触发 | 玩家看到什么 | 玩家能做什么 | 落点 |
|---|---|---|---|---|
| F1 | 拒绝定位权限 | 顶部横幅：「需要位置权限才能找到附近地标」 | 「去设置」→ 授权后自动重试 | P01 |
| F2 | 拒绝相机权限 | 全屏空态：「需要相机权限才能拍照打卡」 | 「去设置」/「返回详情」 | P03 |
| F3 | 精度 > 20m | 浮层：「定位还不够准（±45m），到开阔处等一等」 | 自动重试 3 次 + 手动重试 | P03 |
| F4 | 距离 > 30m | 「还差 68 米，再走近一点」+ 实时距离 | 走近后按钮自动可用 | P03 |
| F5 | 断网 | 顶部离线条：「离线中，打卡会存草稿」 | 继续拍，存草稿；总览进度标「未同步」 | P01/P03/P05 |
| F6 | 上传失败 / 5xx | 「没提交成功，已存草稿」+ 重试 | 手动重试；联网自动补传 | P03/P04 |
| F7 | 照片无效 | 「这张照片用不了：拍摄时间超出 5 分钟」 | 一键重拍（≤3 步） | P03/P04 |
| F8 | 片区内未集齐 | 灰锁格 + 「还差 2 块，去地图找对应的地标打卡」+ 4 个地标打卡状态清单 | 回 P01，或点清单里的地标 | P05 片区拼图 |
| F9 | 重复打卡 | 「今天已经打过卡了」+「查看我的拼图」 | 直接进该片区 2×2 | P02/P03 |
| F10 | 冷启动加载 | 骨架屏 ≤3s | 超时给「重新加载」 | P01/P02/P05 |
| **F11** | 点未开放片区 | 灰锁占位 + 「这个片区下一版开放」，已合成部分照常可见 | 退回总览，不阻塞 | P05 总览 |

原则：**没有死路**。每个异常态至少一个主行动 + 一个退路（返回）。
