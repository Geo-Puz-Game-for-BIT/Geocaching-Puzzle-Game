## D 服务端联调

1. 新增 `GET /checkins?attemptId=<attemptId>`。
2. 按 attempt 返回 `200 / 202 / 404(CHECKIN_NOT_FOUND)`，不能用同用户同地标的历史成功记录代替本次 attempt。
3. 在同一数据库事务内完成 challenge 校验、消费、打卡写入、碎片发放和审计写入。
4. 保证 POST 事务提交后 GET 可立即读到同一记录；同 attempt 重试返回同一 receipt。
5. 将 `geo.ts` 的三处定位精度门限统一为 30 m，并同步错误文档。

## 联调验收

- HTTP 覆盖：`200 / 202 / 404(CHECKIN_NOT_FOUND) / 普通 404 / 405 / 5xx / 超时`。
- 数据覆盖：正常提交、并发提交、同 attempt 重试、不同请求冲突、事务回滚。
- 恢复路径最终计数必须满足：`checkin=1`、`grant=1`、`audit=1`。
- Android UNKNOWN 草稿恢复只允许再次查询；确认成功后才清草稿，确认不存在后才允许新 attempt。
- D 提供服务版本、部署时间、脱敏请求响应和数据库计数。
