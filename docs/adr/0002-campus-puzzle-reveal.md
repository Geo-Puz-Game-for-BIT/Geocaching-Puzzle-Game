# ADR 0002：良乡三校区地图碎片与探索迷雾

## 状态

已接受，2026-10-21。坐标仍待实地核验。

## 背景

首版寻宝范围分为北、东、南三个校区区域，每个区域选择四个地标。早期任务表中的单张 3×3 拖拽拼图与十二个地标不匹配；本 ADR 将当前验收范围改为三个校区各 2×2、共十二块，打卡后自动点亮。任务表中的 `S1-A-01`、`S1-C-02`、`S1-C-07`、`S1-C-08` 及其拖拽/摆放恢复标准需要管理同学同步修订；若仍要拖拽玩法，应另立扩展任务，不作为本版通过条件。

## 决策

- 北校区：北湖、综教、学服、图书馆。
- 东校区：甘棠、勤园、文萃、文博中心。
- 南校区：疏桐、博雅、理教、工业生态楼。
- 每个校区独立使用 2×2 的四块进度，共十二块。
- 每个碎片稳定绑定一个 `landmarkId` 和 `fragmentId`，打卡成功后自动解锁，不要求玩家拖动归位。
- 完成地标后驱散其对应分块内的全部迷雾，而不是按地标中心扩大一个圆形范围。每个地标必须落在自己所属分块内。
- 展示层支持 `GRID` 与 `FOG_OF_WAR` 两种模式，两种模式共享同一套碎片进度。
- 地标打卡范围使用独立的 `CheckInArea` 配置。开阔场地可采用圆形，建筑和狭长区域可采用任意多边形；多边形顶点以地标中心的米制偏移保存，调整尺寸和方向时不需要修改地图适配器。
- 不规则地图以后通过碎片蒙版或多边形资源实现，不改变打卡和奖励接口。
- 当前目录坐标只用于开发演示，全部标记为 `coordinateVerified = false`。正式开放打卡前必须逐点实测并评审安全、拍摄和通行条件。
- 学校官方良乡校区平面示意图可核对北、东、南片区和建筑关系，但 PDF 没有地理配准信息。当前四块的临时多边形由每区四个演示坐标生成；正式边界需要在实测坐标与官方图对齐后冻结。

## 结果

规则 2×2 便于第一阶段验收和调试；战争迷雾更符合探索主题，可作为默认玩家界面。云端只需保存碎片拥有关系，不需要保存玩家拖动位置。后续替换真实校园底图或不规则蒙版时，客户端仍使用相同的十二个碎片 ID。
